# 💰 **Expense Tracker Using OWL**


A modern expense tracking application built with **OWL (Odoo Web Library)**, **JavaScript ES6**, **HTML5**, **CSS3**, and **Bootstrap 5**.

The application helps users manage **income and expenses**, track **budgets**, visualize **financial data**, and export transactions with a **clean and responsive UI**.

---

# 🚀 **Features**

## 📊 Dashboard Analytics

Real-time financial overview including:

- 💰 Total Balance  
- 📈 Total Income  
- 📉 Total Expenses  
- 💵 Total Savings  

---

## 💸 Transaction Management

Full CRUD system:

- ➕ Add new transactions  
- ✏️ Edit existing transactions  
- 🗑️ Delete transactions safely  
- 🏷️ Categorize income and expenses  

---

## 🧾 Budget Tracking

- Set monthly budget goal  
- Live budget usage percentage  
- Visual progress bar indicator  
- ⚠️ Warning state when budget exceeds threshold  

---

## 📊 Data Visualization

Interactive charts using **Chart.js**:

- 🍩 Expense breakdown by category (Doughnut chart)  
- 📊 Income vs Expense comparison (Bar chart)  

---

## 📤 Export System

- Export all transactions to CSV  
- Downloadable file generation using Blob API  
- Theme switching support  

---

## 💾 Local Storage Persistence

- All data saved in browser localStorage  
- Automatic restore on reload  

---

## 📱 Responsive UI

Fully responsive design built with **Bootstrap 5**:

- 📱 Mobile friendly  
- 📟 Tablet optimized  
- 🖥️ Desktop ready
